Ten looks, one system

Every screen keeps your layout element for element. What changes is the system underneath: one set of tokens, one button, one tab bar, one segmented control, one chip, one row. Each direction below is that same system with different structure, shape and type. Edge Mac and Edge Lift re-imagine Edge with what you liked from Native and Tactile. Quiet is kept for comparison. Gray or warm neutrals, light or dark, apply to all six.

The directions and where they come from

Quiet

Every pane is a sheet one step lighter than the canvas, no dividers, capsule controls and pill tabs.

Kept for comparison. Calm, but it reads as Linear's 2026 inset pane.

Edge

Quiet, with the frame squared off. The rail and panes run into the window's corners and meet at a single border, instead of sitting as rounded sheets with gray gutters around them. Every control keeps Quiet's rounded shape.

From your note: roundness in the controls, not in the window frame.

Edge Mac

Edge, tuned like a Mac app: the system font and its tighter rhythm, pane tabs as a segmented control, the top-bar icons in one capsule, flat controls.

Native's tabs and density on Edge's frame.

Edge Lift

Edge with Inter tightened and a slight physical lift on everything clickable: tabs as a segmented control with a lifted thumb, buttons, selection and chips.

Native's tabs and density, Tactile's lift, Edge's frame.

Answer

After Perplexity, on Edge's frame. The chat reads like an answer engine: your message is a headline, Ri's reply reads like an article under it, tool steps collapse into a small pill, changed files show as source cards.

A different idea of what a chat with Ri is: questions and answers, not a thread of bubbles.

Tonal

After Google's Material 3 Expressive, in grays. Pill-shaped selection in the rail, tabs with an indicator bar, outlined segmented buttons with a check on the selected one, 8px chips, an elevated rounded chat input, a floating Create button, Roboto Flex.

Google's design culture next to Edge Mac's Apple one.

Native

After macOS 26 Finder, Mail and Notes, in today's colors. The rail floats as a rounded panel inside the window, panes run flush with a split divider, pane tabs are a segmented control, toolbar icons sit in one capsule group, system font.

Ri as a Mac app that belongs on a Mac.

Tactile

After Attio, Stripe and Resend, in today's colors. Crisp hairlines, controls with a slight physical lift, raised tabs and selection, rows separated like a well-made table.

The polish of the best SaaS tools: everything clickable looks clickable.

Crisp

One flat plane cut by low-contrast hairlines. Radius set by height, underline tabs, Geist type.

From Conductor and Vercel.

Dense

Compact rows, one-line tasks, mono for counts and times, 24px controls.

From Cursor 3's agents window, Zed and Raycast.

Rules for agents building screens

  1. Use the primitives. No raw <button>, tab bar or segmented control outside components/ui.
  2. Sentence case everywhere. No uppercase, no letter spacing on labels.
  3. Six type sizes. No arbitrary text-[Npx].
  4. Four text colors. No opacity on text.
  5. Color means something. Semantic tokens only, no palette classes.
  6. Borders need a reason. Inputs, scroll edges, and the hairlines a direction defines. Never around a list row.
  7. One primary per view. Only the ship moment may use the done color.
  8. Status is a dot and words. Never a tinted card or a colored border.
  9. Circle completes, square selects.
  10. Concentric corners. Inner radius is outer radius minus padding.
