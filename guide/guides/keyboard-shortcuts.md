---
title: Keyboard shortcuts
description: Every keyboard shortcut in Ri, so you can move through your work without reaching for the mouse.
---

On Windows and Linux, use Ctrl wherever this page says ⌘. Shortcuts that say Ctrl use Ctrl on every computer, including a Mac.

## Anywhere

| Keys | What it does |
| --- | --- |
| ⌘K | Search, and every command in Ri. |
| ⌘⇧K | Quick Capture. |
| ⌘J | Voice chat. |
| ⌘⇧J | Open the scratchpad, or close it from inside. |
| ⌘I | Put the cursor in the chat box. |
| ⌘E | Close the agent or chat you're in and go back to your Home. From your Home, reopen your latest chat. |
| ⌘\ | Show or hide the rail. |

In a team, ⌘J and ⌘⇧K are off.

## Search

| Keys | What it does |
| --- | --- |
| Tab and Shift+Tab | Move to the next or previous filter across the top, like Tasks or Notes. |
| Backspace | Go back to All, when the cursor is at the start of the box. |
| `>` | Show commands. `task:`, `note:`, `decision:` and `stream:` pick their filter the same way. |
| ↑ and ↓ | Move through the results. Enter opens one. |

## Writing a message

| Keys | What it does |
| --- | --- |
| Enter | Send. On a touch screen, Enter starts a new line, and the send button sends. |
| Shift+Enter | Start a new line. |
| ⌘Enter | Send, on any device. |
| `@` | Mention a task, note, agent, app, Connector or file. ← and → switch between the kinds before you type a search. |
| `@#` | Mention a GitHub issue or pull request. |

In Quick Capture, Enter or ⌘Enter captures.

## Tasks and notes

| Keys | What it does |
| --- | --- |
| ⌘Enter | Open the task or note you're looking at as a full page. |

## In a chat

| Keys | What it does |
| --- | --- |
| Ctrl+\` | Show or hide the terminal. |
| Ctrl+. | Show or hide the side panel. |
| ⌘P | Go to a file in the chat's folder. |
| ⌘K | Clear the terminal, when it has the focus. Everywhere else ⌘K is search. |

## Viewing a file

| Keys | What it does |
| --- | --- |
| ← and → | The previous or next file from the same chat. |
| + and - | Zoom an image in or out. |
| 0 | Fit the image to the window. |
| Esc | Close the file. |

## The rail

| Keys | What it does |
| --- | --- |
| Esc | Stop selecting chats to archive. |

## Desktop app

| Keys | What it does |
| --- | --- |
| ⌘[ and ⌘] | Back and forward. |
| ⌘⇧K, from any app | Quick Capture, once you turn on **Global Quick Capture** in **Settings**, under **This computer**. You can choose other keys there. |
