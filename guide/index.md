Ri is where you and your AI agents work from the same list. Your tasks, notes and agents live in one place, on a computer you own. Hand off work in a sentence, walk away, and come back when an agent needs you.

Ri runs your agents on the AI plans you already pay for: Claude Code, Codex, Cursor, OpenCode and Antigravity. There's no new AI bill and no API key to manage.

## Start here

- [Install Ri](/docs/getting-started/install) on a Mac, Windows or Linux computer, or on a server.
- [Your first run](/docs/getting-started/first-run) covers what Ri asks the first time it opens.
- [Your first agent and chat](/docs/getting-started/first-agent) hands off a real piece of work.
- [Your phone and other devices](/docs/getting-started/devices) shows how to reach Ri away from the computer it runs on.

## How these docs are organized

- **Getting started** takes you from the download to your first handed-off task.
- **How Ri works** explains each part of Ri and why it's there. Start with [your Home](/docs/concepts/home) and [your main chat](/docs/concepts/main-chat).
- **Guides** cover things you do now and then: keeping Ri running, updates, backups, using Ri from other agents, and fixing problems.
- **Reference** lists every `ri` command and every action an agent can take. Both pages are generated from the code, so they match it.

## Words Ri uses

| Word | What it means |
| --- | --- |
| Home | Your Ri: your tasks, notes and chats, and the server that runs your agents, on one computer. |
| Main chat | Your assistant. It sees everything in your Home and keeps it in order. |
| Agent | A folder to work in, what it may use, its purpose and your standing instructions for it. |
| Chat | One piece of work an agent does for you. |
| Harness | The AI tool a chat runs on, like Claude Code or Codex. |
| Deck | Today's short list of what to do next, and why. |
| Stream | Everything you capture, waiting to be sorted. |
| Connectors | Your accounts, like Gmail or Slack, that agents can use. |

## Ask Ri

Ri ships these docs inside every copy, so they always match the version you run. Your chats can read them too: ask your main chat how something works, and it looks the answer up here.
